# Twisted Gyrotropy

Code to run simulations and generate figures for S. Talkington and E. J. Mele "Gyrotropy from Extrinsic Geometry in Twisted Materials", <a href=https://doi.org/10.48550/arXiv.2607.15189> arXiv:2607.15189 (2026) </a>.

Figures are
- bilayer wire array schematic
- twisted bilayer graphene/Bistritzer MacDonald model
- twisted TMD continuum model (twisted bilayer MoTe2)
- twisted bilayer MoTe2 with strain and a displacement field

Dependencies are numpy and matplotlib. The TMD continuum model also works for twisted bilayer WSe2.

Code is also posted on as <a href=https://zenodo.org/records/21399024> Zenodo:21399024</a>.
